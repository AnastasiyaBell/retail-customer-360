# Working agreements

- Use English for repository documentation, code, and report labels.
- Keep original data unchanged and out of version control.
- Never commit credentials or invent findings, performance metrics, or business impact.
- Keep SQL transformations reviewable and document metric definitions.
- Prevent future-data leakage in all predictive features and labels.
- Separate observed behaviour, predictions, causal claims, and scenario assumptions.
- Update README status as milestones are actually completed.
